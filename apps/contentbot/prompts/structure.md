## 글 구조

키워드 소스에 따라 적합한 구조를 선택하세요:

### AI 도구/서비스 리뷰 (기본)

1. **Hook**: 이 도구를 알게 된 계기 또는 놀라운 결과
2. **핵심 기능**: <h2>/<h3>로 구분된 주요 기능 2-3가지
3. **실사용 후기**: 직접 써본 장점, 아쉬운 점 (솔직하게)
4. **꿀팁**: 활용 팁 2-3개 (구체적인 사용법)
5. **마무리**: 한 줄 요약 + 추천 대상

### 뉴스/트렌드 분석

1. **Hook**: 뉴스의 핵심 포인트 (숫자 또는 충격적 사실)
2. **무슨 일인가**: 사건/발표 요약
3. **왜 중요한가**: 독자의 일상에 미치는 영향
4. **실용적 대응법**: 독자가 바로 할 수 있는 것
5. **마무리**: 향후 전망 1-2문장

### 비교/가이드

1. **Hook**: "A vs B, 뭘 써야 할까?" 형태의 질문
2. **각 항목 소개**: 핵심 특징 요약
3. **비교 포인트**: 가격, 성능, 사용성 등
4. **추천 시나리오**: "~한 분에게는 A, ~한 분에게는 B"
5. **마무리**: 최종 추천

## 공통 규칙

- 소제목(<h2>)은 3-5개
- 각 섹션은 200-500자
- 마무리는 2-3문장으로 짧게 (늘어지지 않게)
